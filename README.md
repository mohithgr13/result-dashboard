# result-dashboard
📊 Student Result Dashboard

The page at https://mohithgr13.github.io/result-dashboard/ is a web-based result analytics dashboard designed to help users enter, manage, and analyze student results:

What it does (based on the page content):

It lets you add subjects and specify pass marks.
You can input student data such as names and their marks.
Once marks are entered, the dashboard calculates and displays key performance statistics for all students, including:
Total number of students
Number passed / failed
Class average
Top performer (topper)
Rank list of students
Details on each student’s total, average, grade, and subject-wise performance

The interface appears to be a front-end tool built in HTML/CSS/JavaScript that runs entirely in the browser, meaning it doesn’t need a backend server — you interact with it directly in the page.

This kind of dashboard is typically used in educational or project contexts to quickly evaluate student performance data without manual calculation — essentially a result management and analytics tool you can use or customize as needed.
